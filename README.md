## Contributing

- **Reporting an issue:** Search the existing issues first to avoid duplicates. If nothing matches, open a new issue with a clear description and the steps needed to reproduce it.
- **Submitting a pull request:** Fork the repository or create a branch, and keep your changes focused on a single concern. Reference the related issue in your PR description and open the pull request against the `main` branch.
